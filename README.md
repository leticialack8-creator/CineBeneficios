
# 🎬 CineBenefícios
## 🌐 Acesse o projeto

[Clique aqui para visualizar o site funcionando](https://leticialack8-creator.github.io/CineBeneficios/)

Projeto acadêmico de uma interface web para apresentação de filmes e cupons de desconto demonstrativos.

## Sobre o projeto

O CineBenefícios é um projeto desenvolvido durante meus estudos em Análise e Desenvolvimento de Sistemas. O objetivo é praticar a construção de interfaces responsivas e a implementação de funcionalidades interativas com JavaScript.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Navegação entre as seções da página
- Pesquisa de filmes por nome
- Exibição e ocultação de detalhes dos filmes
- Cópia de códigos promocionais fictícios
- Layout adaptável para diferentes tamanhos de tela

## Como executar

1. Baixe ou clone o repositório.
2. Abra o arquivo `index.html` em seu navegador.
3. Explore as funcionalidades disponíveis.

## Observações

Os filmes e os cupons são demonstrativos. O projeto não realiza vendas de ingressos nem integra serviços reais de cinema.

## Desenvolvimento

Projeto acadêmico desenvolvido com apoio de ferramentas de inteligência artificial para aprendizado e aperfeiçoamento do código.
